# Ordliste

| Ord | Betydning |
| --- | --- |
| **Agent** | En AI, der kan bruge værktøjer, f.eks. læse og skrive filer, og arbejde i flere trin |
| **AGENTS.md** | En fil med faste regler, som agenten læser ved hver opgave i projektet |
| **API-nøgle** | En slags adgangskode, der giver OpenCode adgang til en betalt model. Del den aldrig |
| **Build** | Den indbyggede agent, der udfører opgaver og retter i filer |
| **CSV** | En simpel tekstfil med data i kolonner. Kan åbnes i Excel |
| **Frontmatter** | Indstillingerne øverst i en agent-, skill- eller kommandofil mellem to `---` |
| **Git** | Et program til versionsstyring. Kræves, for at fortryd kan rulle filer tilbage |
| **Hjælpeagent** (subagent) | En agent, som hovedagenten sender en delopgave til |
| **Kommando** | En gemt opgave, du starter med `/navn` |
| **Kontekst** | Alt det, modellen har "i hovedet" i en samtale: dine beskeder, svar og læste filer |
| **Markdown (.md)** | Almindelig tekst med enkle tegn til formatering, f.eks. `#` for overskrift |
| **MCP** | En standard, der lader agenten forbinde til andre programmer og tjenester |
| **Model** | Den AI, der tænker for agenten, f.eks. en gratis model eller Claude |
| **Plan** | Den indbyggede agent, der undersøger og planlægger uden at rette i dine filer |
| **Projekt** | Den mappe, agenten arbejder i |
| **Prompt** | Den opgave eller besked, du skriver til agenten |
| **Rettigheder** (permissions) | Regler for, hvad agenten må: allow, ask eller deny |
| **Samtale** (session) | En samtale med agenten. Den husker alt i samme samtale, men ikke på tværs |
| **Skill** | En opskrift på en arbejdsgang i en `SKILL.md`, som agenten henter, når den skal bruge den |
| **Terminal** | Et vindue, hvor man styrer computeren med tekstkommandoer. Ikke nødvendigt på kurset |
| **Udbyder** (provider) | Firmaet bag en model, f.eks. Anthropic, OpenAI eller Mistral |
| **Websøgning** (websearch) | Værktøjet, der lader agenten søge på nettet gennem en søgetjeneste |
| **Værktøj** (tool) | En handling, agenten kan udføre, f.eks. læse en fil eller hente en webside |
