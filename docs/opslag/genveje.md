# Genveje og kommandoer

## Tegn i tekstfeltet

| Skriv | Det gør |
| --- | --- |
| `@` | Vælg en fil i projektet, som agenten skal bruge |
| `@navn` | Peg på en bestemt skill eller agent |
| `/` | Vis listen over kommandoer |
| `!` | Kør en kommando på computeren direkte. Undgå det, hvis du ikke ved, hvad kommandoen gør |

## De vigtigste kommandoer

| Kommando | Det gør |
| --- | --- |
| `/new` | Start en ny samtale |
| `/sessions` | Find en tidligere samtale |
| `/models` | Vælg model |
| `/agents` | Vælg agent, f.eks. Plan eller Build |
| `/undo` | Fortryd agentens seneste svar |
| `/redo` | Fortryd fortrydelsen |
| `/btw` | Stil et spørgsmål ved siden af, som ikke bliver en del af samtalen |

I skrivebordsprogrammet findes de fleste af disse også som knapper og menuer.

## Tastaturgenveje

| Genvej | Det gør |
| --- | --- |
| ++enter++ | Send beskeden |
| ++ctrl+o++ | Tilføj et projekt (++cmd+o++ på Mac) |
| ++ctrl+p++ | Åbn kommandopaletten med alle handlinger (++cmd+p++ på Mac) |
| ++ctrl+v++ | Sæt en fil eller et skærmbillede ind i beskeden (++cmd+v++ på Mac) |

Genvejene kan variere mellem versioner og mellem Windows og Mac. Kommandopaletten viser altid de genveje, der gælder i din version.
